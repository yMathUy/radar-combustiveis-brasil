# Brazil Fuel Price Radar

A static and automated dashboard for monitoring fuel prices in Brazil using official public data from the Brazilian National Agency of Petroleum, Natural Gas and Biofuels (ANP).

The project downloads, cleans, aggregates and publishes fuel price data through a fully automated pipeline powered by Python, GitHub Actions and GitHub Pages.

## Live Demo

[Open the dashboard](https://ymathuy.github.io/radar-combustiveis-brasil/)

## Overview

Brazil Fuel Price Radar provides a simple way to explore recent fuel price information across the country.

The dashboard currently includes:

- National average fuel prices for the latest complete reporting week
- Median, minimum and maximum observed prices
- Number of stations included in the analysis
- Weekly national price trends
- State-level gasoline price ranking
- Automatic data updates and deployment
- Responsive layout for desktop and mobile devices

## Data Source

The project uses official open data published by ANP.

ANP collects fuel price observations from fuel stations across Brazil. The values shown in this dashboard represent the stations included in the agency's surveys and may not cover every station operating in each state or municipality.

Partial reporting weeks are excluded from the main analyses.

## How It Works

The project follows this data pipeline:

```text
ANP public dataset
        ↓
Download raw files
        ↓
Clean and standardize records
        ↓
Generate weekly aggregated datasets
        ↓
Export dashboard-ready JSON files
        ↓
Publish the static site with GitHub Pages
```

The main scripts are executed in this order:

```text
src/download.py
src/clean_data.py
src/aggregate_data.py
src/export_dashboard_data.py
```

## Running the Project Locally

### 1. Clone the repository

```bash
git clone https://github.com/yMathUy/radar-combustiveis-brasil.git
cd radar-combustiveis-brasil
```

### 2. Create a virtual environment

#### Windows

```powershell
python -m venv .venv
.venv\Scripts\activate
```

#### Linux or macOS

```bash
python -m venv .venv
source .venv/bin/activate
```

### 3. Install the dependencies

```bash
python -m pip install --upgrade pip
python -m pip install pandas requests
```

### 4. Run the complete data pipeline

```bash
python src/download.py
python src/clean_data.py
python src/aggregate_data.py
python src/export_dashboard_data.py
```

### 5. Start the local web server

```bash
python -m http.server 8000 --directory docs
```

Open the following address in your browser:

```text
http://localhost:8000
```

The dashboard must be served through a local HTTP server because the frontend loads JSON files with the Fetch API.

## Generated Dashboard Files

The frontend reads the following files:

| File | Purpose |
|---|---|
| `docs/data/metadata.json` | Reporting period, export timestamp and ranking rules |
| `docs/data/latest_national_prices.json` | Latest national price statistics |
| `docs/data/latest_state_gasoline_prices.json` | State-level gasoline ranking |
| `docs/data/weekly_national_trends.json` | Historical weekly series used by the line chart |

These files are generated by:

```bash
python src/export_dashboard_data.py
```

## Automated Updates

The GitHub Actions workflow is stored at:

```text
.github/workflows/update-dashboard.yml
```

The workflow can be started manually from the **Actions** tab and is also scheduled to run every Monday.

During each successful execution, GitHub Actions:

1. Checks out the repository
2. Configures Python
3. Installs the required dependencies
4. Downloads the ANP dataset
5. Cleans and standardizes the data
6. Generates the aggregated CSV files
7. Exports the JSON files used by the dashboard
8. Validates the generated outputs
9. Commits updated datasets when changes are detected
10. Publishes the website through GitHub Pages

The computer of the repository owner does not need to be turned on for scheduled executions.

## GitHub Pages

Because the dashboard is fully static, it can be hosted directly by GitHub Pages without a backend server or database.

## Data Quality Considerations

The pipeline separates raw, processed and aggregated files to make transformations easier to inspect.

Important considerations:

- ANP data availability may be delayed
- Network failures may temporarily prevent automatic updates
- The export timestamp does not necessarily mean that ANP published a newer reporting week
- Partial weeks are excluded from the main analyses
- State rankings require a minimum number of observations
- Surveyed stations may not represent every station operating in a region

The reporting period displayed on the website should be used to confirm the actual freshness of the fuel price data.

To run the automation manually:

1. Open the repository on GitHub
2. Go to **Actions**
3. Select **Update Fuel Dashboard**
4. Click **Run workflow**
5. Select the `main` branch
6. Confirm the execution

The execution logs show each stage of the pipeline and help identify download, processing, validation or deployment failures.
